# SimpServer

## About

A .NET CLI to host **static** webpages with configured directory on local network

## Features

1. Lightweight program, quick setup and no dependency install required
2. Cool terminal colors

## How to use?

Simply enter the path of directory and choose whether to serve it locally on your PC or on your router network.

> [!TIP]
> You can serve multiple directories by simply using multiple instances of this application

## Known issues

1. Doesn't work if *index.html* is not present, even if present as another extension(index.htm)
